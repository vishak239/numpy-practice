# NumPy Practice

A single Python script of NumPy exercises I wrote while learning numerical computing for data science. The code includes comments that explain each step.

## What's Covered

`test_numpy.py` walks through:

- Creating arrays: `array`, `zeros`, `ones`, `full`, `eye`, `arange`, `linspace`
- Array dimensions and random integers
- Reshaping: `reshape`, `ravel`, `transpose`
- Indexing and slicing in 1-D and 2-D
- Joining and splitting: `concatenate`, `array_split`, `hsplit`
- Math functions: `sqrt`, `log`, `exp`, `mod`
- Broadcasting
- Matrix multiplication with `dot`

## How to Run

```bash
pip install numpy
python test_numpy.py
```
